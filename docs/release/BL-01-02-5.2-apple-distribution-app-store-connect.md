# Task 5.2 — Apple Distribution certificate + App Store Connect app record

**Story:** BL-01+02 · **Task:** 5.2 · **Deferred since:** 2026-05-16  
**Requirements:** AC-005, AC-008  
**Blocks:** Task **3.2** (Archive signing) · iOS path of **5.4**

---

## Goal

1. Create/install an **Apple Distribution** code-signing identity on your Mac.  
2. Register bundle ID **`com.chicademy.mitoosa`** (if not already).  
3. Create the **App Store Connect** app record so TestFlight can accept uploads.

---

## Before you start

- [ ] **Apple Developer Program** membership (Admin or Account Holder for cert creation; App Manager can create ASC apps).
- [ ] macOS with **Keychain Access** and **Xcode**.
- [ ] Legal app name and SKU decided (examples below use `miToosa`).

---

## Part A — Register the App ID (bundle identifier)

1. Open [Apple Developer → Identifiers](https://developer.apple.com/account/resources/identifiers/list).
2. Click **+** → **App IDs** → **App** → Continue.
3. **Description:** `miToosa`
4. **Bundle ID:** Explicit → `com.chicademy.mitoosa`
5. Enable capabilities you need today (none required for base Flutter app unless you added Push, Sign in with Apple, etc.).
6. **Register**.

**Check:** Identifier list contains `com.chicademy.mitoosa`.

---

## Part B — Create Apple Distribution certificate

### Option 1 — Let Xcode create it (easiest; pairs with task 3.2)

1. Open `ios/Runner.xcworkspace` in Xcode.
2. **Runner** target → **Signing & Capabilities** → **Automatically manage signing** ON.
3. Select your **Team**.
4. Xcode may prompt to create certificates; allow it.
5. In Keychain Access → **login** keychain → **My Certificates**, look for **Apple Distribution: …** or **Apple Development** (Distribution appears when archiving for App Store).

### Option 2 — Manual via Developer portal

1. [Certificates](https://developer.apple.com/account/resources/certificates/list) → **+**.
2. Type: **Apple Distribution** (App Store Connect and Ad Hoc).
3. Follow steps to create a **Certificate Signing Request (CSR)** on Mac:
   - Open **Keychain Access** → **Certificate Assistant** → **Request a Certificate From a Certificate Authority**.
   - Email: your Apple ID email; **Saved to disk**.
4. Upload the `.certSigningRequest`, download the `.cer`, double-click to install in Keychain.
5. Optional but recommended: export **.p12** for backup  
   Keychain → certificate → right-click → **Export** → `.p12` → store in password manager only.

**Check:** Keychain shows **Apple Distribution** certificate with a private key underneath (expand the triangle).

---

## Part C — Provisioning profile (automatic vs manual)

For task **3.2**, prefer **Automatic Signing**—Xcode creates/updates **App Store** / **iOS Distribution** profiles.

Manual path (only if you disabled automatic signing):

1. [Profiles](https://developer.apple.com/account/resources/profiles/list) → **+** → **App Store Connect** (or **App Store** distribution).
2. App ID: `com.chicademy.mitoosa`.
3. Select your **Apple Distribution** certificate.
4. Download `.mobileprovision` → double-click to install.

---

## Part D — Create App Store Connect app record

1. Open [App Store Connect](https://appstoreconnect.apple.com).
2. **Apps** → **+** → **New App**.
3. Fill in:

| Field | Example value |
|-------|----------------|
| Platforms | iOS |
| Name | miToosa |
| Primary language | English (U.S.) or your locale |
| Bundle ID | `com.chicademy.mitoosa` (must match Xcode) |
| SKU | `mitoosa-ios` (unique string; never shown to users) |
| User Access | Full Access or as needed |

4. **Create**.

**Check:** App appears under **Apps**; **TestFlight** tab is visible (may be empty until first upload in **5.4**).

---

## Part E — Minimum metadata (optional before first upload)

You can defer store listing work, but Apple may require for external testing later:

- **App Privacy** questionnaire (App Store Connect → app → **App Privacy**).
- **Export compliance** (often handled per-build in TestFlight after upload).

For **Internal Testing** only (task **5.4**), basic app record + successful upload is enough.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| Bundle ID not in dropdown in ASC | Finish Part A first; wait a few minutes and refresh |
| “No signing certificate” in Xcode | Install Distribution cert (Part B); restart Xcode |
| Wrong team | Xcode → Settings → Accounts → select correct team on Signing tab |
