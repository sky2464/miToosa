# Task 3.2 — Xcode automatic signing with provisioning profile

**Story:** BL-01+02 · **Task:** 3.2 · **Deferred since:** 2026-05-16  
**Requirement:** AC-008 (distribution signing via team / automatic profiles)  
**Depends on:** Apple Developer Program membership; task **5.2** recommended first (Distribution cert + App Store Connect app)

---

## Goal

Enable **Automatically manage signing** in Xcode so Debug and Release builds get valid provisioning profiles, and **Product → Archive** succeeds for App Store / TestFlight distribution.

---

## Before you start

- macOS with Xcode installed (open once to accept license and install components).
- Apple ID enrolled in the **Apple Developer Program** for team **TYK6BBNDW5** (or your team).
- Task **5.2** done or in progress: Distribution certificate in Keychain; bundle ID `dev.atoosa.mitoosa` registered.
- Flutter iOS deps installed:

```bash
cd /path/to/mitoosa
flutter pub get
cd ios && pod install && cd ..
```

---

## Step 1 — Sign in to your Apple account in Xcode

1. Open **Xcode**.
2. Menu **Xcode → Settings…** (or **Preferences…** on older Xcode).
3. Tab **Accounts**.
4. Click **+** → **Apple ID** → sign in with the Apple ID tied to the Developer Program.
5. Select the account → confirm team **TYK6BBNDW5** (or your team name) appears under **Team**.

**Check:** Team list shows your organization, not only “Personal Team” (Personal Team cannot distribute to App Store).

---

## Step 2 — Open the workspace (not the `.xcodeproj`)

From the repo root:

```bash
open ios/Runner.xcworkspace
```

**Check:** Project navigator shows **Runner** and **Pods**. If you opened `Runner.xcodeproj` by mistake, close it and open the `.xcworkspace` instead.

---

## Step 3 — Configure signing on the Runner target

1. In the left navigator, click the blue **Runner** project icon.
2. Under **TARGETS**, select **Runner** (not RunnerTests).
3. Open the **Signing & Capabilities** tab.
4. For **Debug** and **Release** (use the configuration dropdown at the top if shown):
  - Enable **Automatically manage signing**.
  - **Team:** select **TYK6BBNDW5** / your organization team.
  - **Bundle Identifier:** must be `dev.atoosa.mitoosa`.
5. Wait for Xcode to resolve signing. Status should show a green check, e.g. “Provisioning profile … Xcode Managed Profile”.

If you see a yellow warning:

- Click **Try Again** or **Download Manual Profiles**.
- Confirm the bundle ID exists under [Certificates, Identifiers & Profiles](https://developer.apple.com/account/resources/identifiers/list) → **Identifiers** → `dev.atoosa.mitoosa`.

**Check:** No red error on Signing & Capabilities for **Release**.

---

## Step 4 — Confirm Release build settings (optional)

1. Still on **Runner** target → **Build Settings**.
2. Search `CODE_SIGN`.
3. Confirm:
  - **Code Signing Style** = Automatic (for Release).
  - **Development Team** = your team ID (repo default: `TYK6BBNDW5`).

Do **not** hand-edit `ios/Runner.xcodeproj/project.pbxproj` for team ID; Xcode will rewrite that file.

---

## Step 5 — Verify Archive (provisioning for distribution)

1. Scheme toolbar: **Runner** scheme.
2. Destination: **Any iOS Device (arm64)** — not a simulator.
3. Menu **Product → Archive**.
4. Wait for the build to finish (several minutes on first run).

**Pass:**

- Archive completes; **Organizer** opens with your archive listed.
- No errors such as “No profiles for 'dev.atoosa.mitoosa' were found” or “Signing certificate not found”.

**Fail → common fixes:**


| Error                              | Action                                                                        |
| ---------------------------------- | ----------------------------------------------------------------------------- |
| No profiles found                  | Repeat Step 1; correct Team in Step 3; register bundle ID in Developer portal |
| Signing certificate not found      | Complete task **5.2** (Distribution certificate in Keychain)                  |
| Archive greyed / wrong destination | Set destination to **Any iOS Device (arm64)**                                 |


You do **not** need to upload yet; upload is task **5.4**.

---

## Step 6 — Record completion

- Automatic signing enabled for **Runner** (Debug + Release).
- Bundle ID `dev.atoosa.mitoosa` on both configurations.
- **Product → Archive** succeeds once.

Mark task **3.2** complete in Master-Plan. Proceed to **5.4** when **5.1**, **5.2**, and **5.3** are done.
