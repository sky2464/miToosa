# Archived docs

## Workflow

- Keep active specs and plans in the `docs/` root while they are being worked.
- Once a spec or plan is complete, verified, and archived, move it into this folder.
- Treat archived docs as historical reference; only update them for correction of the record.

## Notes

- Relative links inside archived docs should continue to work from this folder.
- If a root-level doc points to an archived file, update the link so the archive location stays obvious.
