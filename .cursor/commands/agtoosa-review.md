## Host Mode Execution (IDE Host Mode Bridge)

- **Enter plan:** `SwitchMode` → `plan` if not already in plan; user fallback: Shift+Tab
- **Plan window:** persona analysis, Iron Law hypotheses, cross-model gate planning, findings synthesis as structured plan; include `### Plan-Mode Review Briefing (findings)` in the plan
- **Switch to agent:** when briefing complete, print `HOST-MODE: plan complete → switching to agent for AgToosa artifacts`, then `SwitchMode` → `agent` for `review-*.md`, evidence ledger, Master-Plan updates, simplification, verdict gate
- **Forbidden in plan mode:** writing review artifacts or mutating Master-Plan before handoff; never queue plan→agent in the same turn
